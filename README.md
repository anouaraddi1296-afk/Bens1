# My Hacking Toolkit

Welcome to my Python Toolkit! This is a collection of scripts I built while learning Python and Cybersecurity on Termux.

## Features
- **Port Scanner**: Scans common ports on a target IP/Domain.
- **Link Extractor**: Extracts all absolute links from a webpage and saves them to `links.txt`.
- **Password Generator**: Generates strong and random passwords.
- **IP Info Fetcher**: Retrieves location and ISP info for any IP or Domain.

## How to use
1. Clone the repository.
2. Install requirements: `pip install requests beautifulsoup4`
3. Run the main menu: `python toolkit.py`
